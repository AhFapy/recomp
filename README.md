# Recomp

App de hábitos, comida y peso de Javi y Ahmed. HTML estático + Supabase (proyecto Trud Sales, tablas `recomp_*`). Se entra con la cuenta del panel; solo org_admins.

- `index.html`: toda la app.
- `supabase/001-recomp.sql`: tablas y RLS (ya aplicada).
- Despliegue: Vercel, sin build (Framework: Other, sin comando de build).
